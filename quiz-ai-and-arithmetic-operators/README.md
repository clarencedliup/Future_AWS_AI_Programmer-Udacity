# Quiz: AI and Arithmetic Operators

## Overview
This folder contains my solutions for the Python arithmetic operator exercises in the Udacity Future AWS AI Programmer track.

## Scenarios Addressed
1. **Evaluating Model Performance:** Calculated the mean prediction accuracy of a machine learning model over a three-month period.
2. **Managing Data Storage:** Calculated total storage requirements for multiple image datasets and determined remaining capacity on a new storage device, demonstrating unit conversions (KB to MB).

## Files
* `arithmetic-operators.ipynb`: My working notebook containing the calculations.
* `arithmetic-operators-solution.ipynb`: Working notebook containing the solutions.
